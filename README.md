# meu-guia-dev
Acervo de documentação e referências técnicas: reúne comandos essenciais, explicações de arquitetura, padrões e guias para uso em projetos de desenvolvimento de software.
Este repositório centraliza minhas anotações técnicas e guias de sobrevivência. Os conteúdos foram inicialmente consolidados durante meus estudos diários em documentos privados e migrados para o GitHub para servir como uma base de conhecimento pública, open-source e de fácil consulta.
