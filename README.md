# meu-guia-dev

Acervo de documentação e referências técnicas: reúne comandos essenciais, explicações de arquitetura, padrões e guias para uso em projetos de desenvolvimento de software.

Este repositório centraliza minhas anotações técnicas e guias de sobrevivência. Os conteúdos foram inicialmente consolidados durante meus estudos diários em documentos privados e migrados para o GitHub para servir como uma base de conhecimento pública, open-source e de fácil consulta.

---

## 🗺️ Estrutura do Repositório

Navegue pelas pastas para encontrar os comandos, snippets de código e conceitos de cada tecnologia:

### 🏛️ [Arquitetura e Conceitos](./arquitetura-e-conceitos/)
Conceitos estruturais, padrões de engenharia e automação de sistemas.
* **`api-design`**: Boas práticas de rotas REST, verbos HTTP e estruturação de payloads.
* **`cron-jobs`**: Sintaxe, comandos do `crontab` e agendamento de tarefas em Unix.

### ☁️ [Backend-as-a-Service (BaaS)](./backend-as-a-service/)
Plataformas de infraestrutura pronta e serviços gerenciados.
* **`supabase`**: Autenticação, banco de dados gerenciado, queries locais e uso da CLI.

### 👥 [Cultura Dev e Git](./cultura-dev-e-git/)
Padrões de trabalho em equipe, versionamento e documentação.
* **`commits`**: Boas práticas e o padrão *Conventional Commits*.
* **`git-github`**: Comandos essenciais de Git e gerenciamento de repositórios.
* **`pull-requests`**: Modelos e boas práticas para revisão de código.
* **`readmes`**: Guias de como estruturar uma boa documentação.

### 📦 [Frameworks e Libs](./frameworks-e-libs/)
Bibliotecas e ecossistemas para turbinar o desenvolvimento no Frontend e Backend.
* **`bcryptsjs`**: Criptografia e hashing de senhas no servidor.
* **`nextauth`**: Estratégias e middlewares de autenticação.
* **`nextjs`** / **`react`**: Frameworks para construção de interfaces modernas e SSR.
* **`playwright`**: Automação de testes End-to-End (E2E), auto-waiting e gerenciamento de contextos de navegadores.
* **`prisma`**: ORM para modelagem e migrações de banco de dados SQL.
* **`shadcn-ui`**: Componentes de interface reutilizáveis e acessíveis.
* **`tanstack-query`**: Gerenciamento de estado assíncrono e cache de APIs.
* **`testes-unitarios`**: Comandos práticos, queries de acessibilidade e asserções com Jest e RTL.
* **`zod`**: Validação de esquemas em tempo de execução e inferência de tipos.
* **`zustand`**: Gerenciamento de estado global leve e performático.

### 💳 [Gateways de Pagamento](./gateways-de-pagamento/)
Integrações financeiras e processamento de transações.
* **`stripe`**: Manipulação de `PaymentIntent`, testes com Stripe CLI e validação de Webhooks.

### 🔤 [Linguagens](./linguagens/)
Fundamentos das linguagens de programação e consulta que utilizo.
* **`typescript`**: Tipagem estática, interfaces, generics e segurança em JS.
* **`postgresql`**: Banco de dados relacional, sintaxe SQL e indexação.

### 🟢 [Runtimes e Backends](./runtimes-e-backends/)
Ambientes de execução para o lado do servidor.
* **`nodejs`**: Arquitetura orientada a eventos, módulos e manipulação de requisições.

---

## 🛠️ Como usar este guia
1. Clique nos links das pastas acima para acessar o diretório correspondente.
2. Cada pasta possui seu próprio arquivo `README.md` detalhado com exemplos práticos prontos para copiar e aplicar.

*Guia mantido constantemente atualizado conforme avanço nos meus estudos diários.*
